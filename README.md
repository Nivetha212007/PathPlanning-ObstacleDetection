# PathPlanning-ObstacleDetection
Professional offline PySide6 autonomous UGV A* simulator.

Run on Windows with one command:
`run.bat`

Features: real A*, 25x20 occupancy grid, interactive add/remove obstacles, automatic replanning from the current UGV cell, UGV animation, metrics, event log, demo/reset controls, and no-path handling.

### Demo visualization
UGV movement is intentionally paced at about 0.5 seconds per grid cell so path following and real-time replanning are easy to observe during demonstrations.
